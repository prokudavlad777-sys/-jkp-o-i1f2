# TropicRTP 1.1 (Paper 26.3)

`/rtp` открывает меню с тремя вариантами:

| Слот | Предмет | Что делает | Доступ |
|------|---------|-----------|--------|
| 1 | Листва дуба | Случайная точка 0–250 блоков от вас | все |
| 2 | Листва сакуры | Рядом со случайным игроком, 300–500 блоков | группа `tropic` |
| 3 | Листва тёмного дуба | 1000–50000 блоков от центра мира | группа `tropic` |

Кулдаун 30 сек после любой телепортации. Всё настраивается в `config.yml` и `messages.yml`.

## Сборка на GitHub
1. Загрузите все файлы в репозиторий (папка `.github` — в корне).
2. **Actions** → сборка запустится сама (или **Run workflow**).
3. Готовый `.jar` — в **Artifacts → TropicRTP**. Положите в `plugins/`.

> При обновлении с 1.0 удалите старые `config.yml` и `messages.yml` в `plugins/TropicRTP/`.

## Права (LuckPerms)
- `tropicrtp.use` — меню и ближний RTP, по умолчанию у всех
- `group.tropic` — автоматически есть у участников группы `tropic` (варианты 2 и 3)
- `tropicrtp.menu.all` — все варианты в обход групп (по умолчанию OP)
- `tropicrtp.bypass` — без кулдауна
- `tropicrtp.admin` — `/rtp reload`
